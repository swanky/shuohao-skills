# 中國古典小說主要女性角色品質基準規劃

## 目標與優先順序

以現有的 `testdata/benchmarks/novel-characters/classic-chinese-novels/紅樓夢-主要女性角色/` 為直接參考，替五部小說完成主要女性角色批次：

- 《紅樓夢》沿用已完成的八位女性角色。
- 《三國演義》《水滸傳》《西遊記》各新製作八位女性角色。
- 《金瓶梅》依外部 repo 的 current visual authority 製作十一位女性角色。

每部小說都先完成女性角色批次，再完成 `CHARACTER-BASELINE-PLAN.md` 的互補主要角色。兩批角色最後去重合併成同一個 `<書名>-主要角色/` 品質基準與同一份報告；除現有《紅樓夢》基準作為遷移起點外，不另外提交女性專屬的最終報告目錄。《金瓶梅》的格式轉換與外貌鎖定另依 [`JINPINGMEI-CROSS-REPO-PLAN.md`](JINPINGMEI-CROSS-REPO-PLAN.md)。

## 《紅樓夢》既有女性角色

《紅樓夢》的女性批次已完成：林黛玉、薛寶釵、王熙鳳、賈探春、史湘雲、妙玉、晴雯、襲人。這八份角色卡與八張預設圖片直接納入未來的十六人綜合報告；林黛玉既有的三張畫風對照圖一併保留。

本批不重做這八位角色，但合併前仍需再次用完整 `紅樓夢.txt` 執行 `validate`，並檢查她們與新增八位主要角色的外貌、配色、聲線、別名及關係有沒有衝突。

## 選角原則

女性角色在《三國演義》《水滸傳》《西遊記》與《金瓶梅》中的稱謂、出場密度與敘事位置各不相同，不能只用本名出現次數排序。掃描與選角應同時考慮：

1. 是否推動重要事件，或能代表作品的一條關鍵人物線。
2. 是否有足夠的言語、行動、關係與逐字引文，可支撐完整角色卡。
3. 是否能與同批角色形成身分、年齡、陣營、氣質、服飾或物種上的差異。
4. 原文是否常以「夫人」「婦人」「女王」「女怪」等泛稱代替本名；若是，必須連同上下文與別名掃描，不能以本名詞頻判斷戲份。
5. 後世戲曲、民間傳說與影視形象只能作為待辨識的文化背景，角色卡的事實與證據仍以本目錄收錄的小說版本為準。

若首批人物的原文材料不足以通過角色卡品質檢查，可依各書候補順序替換；不得以大量無依據推斷硬湊八人。

## 共用產出規格

女性角色卡在工作階段可以分批保存，但正式提交必須等互補主要角色完成後，合成下列單一產物：

```text
testdata/benchmarks/novel-characters/classic-chinese-novels/<書名>-主要角色/
├── <書名>-主要角色-cast.json
├── <書名>-主要角色-cast.md
├── report.html
└── images/
    └── <角色安全檔名>-sheet.png（兩批每位不重複角色一張）
```

共用設定：

- 報告語言為 `zh-TW`；人類可讀內容使用台灣正體中文與台灣慣用詞。
- 生圖風格為 `photoreal`；《三國演義》《水滸傳》採歷史劇試裝定妝照，《西遊記》採保留實體妝造與材質可信度的神怪劇試裝定妝照。
- `persona.evidence` 逐字保留原文，包含原文中的簡體字、異體字與標點。
- 生圖與 TTS 的機器提示詞保持英文。
- 前四部女性批次各八位；《金瓶梅》女性批次十一位。全數建立角色卡、聲音提示詞及角色設定圖；合併後前四部各十六位、《金瓶梅》十九位不重複角色。
- 不以美貌作為女性角色的共用預設；年齡、體態、權力、職業、生活痕跡及個性都要形成具體差異。
- 不把悲劇受害者、反派或妖怪簡化成帶評判性的單一標籤；角色卡需區分原文敘事立場、人物行動與現代分析。

## 分書執行方式

尚待製作的四部原著都超過單次 24 分塊的掃描上限。每部作品應依下列步驟執行：

1. 按章回切成不會出現 `truncated: true` 的掃描段；建議《三國演義》每 30 回、《水滸傳》每 20 回左右、《西遊記》與《金瓶梅》每 25 回一段。
2. 第一趟除了掃描所有角色，另以本文件的首批與候補別名做定向複查，收集被「夫人」「婦人」「娘子」「女王」「女怪」等泛稱遮蔽的段落。
3. 對各段 roster 做全書層級歸併；同一人物的本名、稱謂、婚前婚後身分與妖怪別名不得拆成多人。
4. 檢查每位首批角色是否有足夠的行動、關係與逐字引文。材料不足者依候補順序替換，並把換角理由記錄在工作筆記。
5. 同一部作品的女性批次並行建立角色卡；前四部各八位，《金瓶梅》十一位。產生外貌時，將原文明示與歷史、地域或物種推斷清楚分開；《金瓶梅》另依外部 authority 鎖定外貌。
6. 合成暫存的女性批次 `cast.json` 後，以完整原著執行 `validate`，修正至零錯誤才進入生圖。
7. 每位角色各自產生一張設定圖並人工檢查，但此時不渲染或提交女性專屬的最終報告。
8. 接著依主要角色規劃完成另一批，前四部各合併十六張、《金瓶梅》合併十九張角色卡，再產生與提交唯一一份 Markdown 及 HTML 報告；分塊、roster、工作筆記、分批 JSON 與單卡中間檔不提交。

## 人工檢查重點

除共用結構與圖片品質外，主要女性角色基準另需檢查：

- 沒有把所有年輕女性寫成相同的白皙、纖瘦、柔弱或艷麗外貌。
- 外貌細節有原文依據時優先採用；沒有依據時標示推斷，且推斷符合時代、階級、地域與生活經驗。
- 遇到婚姻控制、性暴力、處決、自盡或戰亂死亡時，文字與圖片不使用獵奇、色情或責怪受害者的呈現方式。
- 女性武將、統治者、店主、宮廷女性、平民與妖怪的姿態和服裝服務於身分與行動，不只服務於美觀。
- 《三國演義》不把後世戲曲妝容與民間傳說直接當成小說事實。
- 《水滸傳》保留原著價值觀作為證據，但人物分析不照抄侮辱性敘事標籤。
- 《西遊記》的佛教、道教與民間神怪元素不混成無來源的通用奇幻造型；宗教人物保持莊重。

## 驗收條件

每部小說必須同時符合下列條件：

- 前四部女性批次各有八位經證據複查的角色，最終 `cast.json` 各有十六位；《金瓶梅》女性批次十一位、最終十九位。所有名稱與別名均沒有重複拆分。
- 對完整原著執行 `validate`，結果零錯誤。
- 每位角色的核心判斷都有原文支撐，推斷均明確標示。
- 該書最終每位角色的設定圖全部存在，臉部、身分、服裝與三視圖一致，比例合理且無文字或浮水印；《金瓶梅》另須與外部 authority 圖及 hash 映射一致。
- 女性八人彼此之間，以及與互補主要角色之間，在年齡、臉型、體態、服裝輪廓、主色、姿態與聲線上都可清楚辨識。
- 角色分析處理了人物的行動與處境，沒有只以美貌、婚姻關係、貞節或善惡標籤定義人物。
- `cast.md` 與 `report.html` 可正常開啟、圖片路徑正確、介面文案為台灣正體中文。
