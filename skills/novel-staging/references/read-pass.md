# 認圖：從場景圖裡認出能站能坐的東西

每個地點（美術場景）認一次，同一個地點的每一場都使用這一份。認出來的清單就是排站位時能使用的全部東西：每個人落在其中一件東西的哪一側。所以清單要跟圖一致，**圖裡有的才寫**。

為什麼看圖、不看提示詞：圖只照提示詞畫了一部分，提示詞裡寫了、圖上沒畫出來的東西很常見（實測：提示詞裡有北端主位高臺，圖上沒有，站位就讓人坐在一個不存在的高臺上，出來的影片每一段都不一樣）。影片和分鏡圖都是照著這張圖出的，站位就得落在這張圖上。

## 看哪一塊

novel-art 的場景設定圖是一張 16:9 的版面：**左上約 72% 寬 × 70% 高是主視角**，右列和底行是細節特寫。只看主視角那一塊認東西；`box` 仍然按**整張圖**的寬高量（左上角 0,0，右下角 1,1），報告會把框畫在整張圖上。

主視角的機位在南側向北看：圖的左邊是西、右邊是東，越往上（越遠）越靠北，越往下（越近）越靠南。

## 寫什麼

1. **只寫人會站在旁邊、坐在上面、走過去的東西**：桌、椅、長凳、沙發、床、櫃檯、臺子、臺階、門、窗、屏風、樓梯、欄杆、柱子、船板、大件擺設。牆上的畫、桌上的茶杯、燈這類小東西不寫，除非它是這個空間裡唯一能當參照的東西。
2. **圖裡看不到的不寫。** art.json 的場景提示詞和錨點只用來幫你認圖裡那件東西叫什麼——提示詞裡寫了、圖上沒有的，一律不寫；圖上有、提示詞沒寫的，照寫。
3. **一件東西一條。** 圍著桌子擺的一圈椅子不單獨寫——坐在桌邊的人就寫在桌子的哪一側，桌子替它們說了；只有主位那一把、離開桌子單獨擺著的椅子、沙發、凳子單獨一條（主位決定誰坐主位）。
4. **名字寫成走位裡說得出口的叫法**，十個字以內，同類的東西用方位或特徵分開（「北端主位太師椅」「東側落地窗」「西牆邊的沙發」）。不寫人名。另一種語言寫進 `alt`。
5. 房間中間一大片空地、門口一塊地方，如果沒有傢俱可以當參照，可以寫成一條（「大廳中央空地」），框住那塊地面。
6. **`box`** 框住這件東西在圖上佔的地方；被前面的東西擋住一部分的，框看得見的那部分加上被擋住的大致範圍。
7. **`plan`** 是把整個房間擺平以後從正上方看：北在上、南在下（機位那一側）、西在左、東在右。按透視推算真實位置和大小——圖上越小、越靠上的東西在平面上越靠北；一張從近處一直伸到遠處的長桌，圖上是個梯形，平面上是一條南北走向的長條；貼著左牆的東西在平面上靠西。**同一個地點裡的東西之間別重疊**，桌子和圍著它的椅子之間留出人坐的地方。
8. **`on`**：人能坐在、站在它上面寫 true（椅子、長凳、床、臺子、臺階、甲板），其餘寫 false。
9. **`round`**：從正上方往下看是圓的或橢圓的寫 true（圓桌、圓地毯、圓形花壇）。人會圍著圓的東西一圈站或坐。

數量：4 到 20 件，按從北（圖的上方、遠處）到南（下方、近處）排。少了排不開人，多了多半是把杯子碗碟也寫進來了。

## 寫完

`readFrom` 寫 `picture`。

```json
{"sceneId":"S01","name":"渡船船艙","readFrom":"picture","items":[
  {"name":"船頭撐篙臺","alt":"bow poling deck","box":[0.30,0.10,0.55,0.22],"plan":[0.30,0.02,0.70,0.10],"on":true}
]}
```

## 還沒有圖

novel-art 只交提示詞，不生圖。圖還沒出時可以先**按 art.json 推算**：主視角提示詞裡寫了的、錨點裡有的大件東西，按提示詞裡的方位擺到平面上。這樣排出來的站位只是草稿——圖出來以後，場景裡的東西不一定跟提示詞一樣，要重新認一遍、核對站位。

推算的寫法：`readFrom` 寫 `prompt`，不寫 `box`（沒有圖可框），其餘規則照舊。報告會在這個地點上標「沒有圖，按設定提示詞推算」。
