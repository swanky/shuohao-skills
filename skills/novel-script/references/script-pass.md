# 寫戲：一集怎麼寫

一次任務寫一集。你拿到 seed 骨架（目標秒數、鉤子、懸念、認領爽點、候選場景人物）、大綱裡這一集的梗概、場景卡與角色資訊、前一集的結尾懸念。產出：把這一集的 `scenes` 從空寫滿。

## 硬規則

1. **時長預算先於一切。** 目標秒數就是牆：臺詞按 4.5 字/秒、動作按 2.5 秒/拍折算，寫完跑 validate 看數。三分鐘一集約 45–55 拍。**寫超先砍動作，寫欠補衝突不補寒暄。**
2. **單句臺詞 ≤ 35 字，一口氣說得完。** 長句拆成兩句，中間可以插一拍動作或對方的反應。
3. **誰的話像誰。** 船伕不說文言，小姐不說市井話。角色的性情、身份、說話方式在 outline 的角色表（有 cast.json 更全）裡——寫之前先讀，寫的時候蓋著名字也認得出是誰在說話。
4. **動作節拍一拍一件事，敘述體，動作要「常見」。** 「胡二爺的手停在半空，笑僵在臉上」是一拍；「氣氛很尷尬」不是畫面，寫不得。動作裡**不許出現引號臺詞**。
   **常見動作是 AI 生成的生命線**——這條戲最終是影片模型演的，它只會演它見過千萬次的動作：

   | 寫法 | 例子 | 生成結果 |
   | --- | --- | --- |
   | ✗ 精確物理互動 | 貨擔撞上船幫，銅鈴碎響。老周伸篙一擋，擔子穩穩落進艙裡 | 篙、擔、船幫三物互動，必崩 |
   | ✓ 常見動作 | 胡二爺挑著擔子上船，老周搭手幫他把擔子卸進艙裡 | 挑擔、搭手、放下，全是常見動作 |

   判據：這個動作在生活影片裡常見嗎？**上船、坐下、遞東西、點頭、回頭、抱緊、站起來**——放心寫；**用工具擋住某物、微表情（睫毛顫）、以寸計的位移（收了半寸）、比喻性畫面（像被霧攥住的繭）**——改寫或刪。戲劇資訊靠常見動作的**組合與時機**給，不靠動作本身的精巧。
5. **每場至少一個動作節拍。** 三句臺詞之間沒有一個畫面動作，就該問自己這場戲觀眾在看什麼。
6. **鉤子不是標籤，是第一拍，而且要在運動中給。** 每集第 1 拍冷開場：鉤子的具象必須帶主體運動——**✗ 靜物特寫一閃（舊皮箱抱在懷裡，指節掐白）✓ 抱著舊皮箱在霧裡跑**。奔跑、追趕、掙脫、猛地按住，都行；靜態細節特寫（掐白的指節、口袋的輪廓）留給第二落點兌現（登船、開箱）。`hookBeat` 認領它——門查位置，必須落在全集前 3 拍內；有沒有運動是寫作紀律，門查不了。上一集的結尾懸念要在開場接住——接住不等於立刻解開。
7. **結尾最後一拍必須是懸念。** 一句沒說完的話、一個沒解釋的動作、一聲來歷不明的響。`cliff` 欄位寫效果說明，戲裡落成具體的一拍。
8. **認領的爽點要有戲扛。** `beatsClaimed` 裡的每個爆點，這一集裡必須有一段連續節拍在兌現它——爆點是演出來的，不是梗概裡說說。

## 修改紀律（錯誤最常從單點修改混進來）

- **改一拍，連讀三拍。** 任何節拍改動後，把前後各一拍連起來重讀一遍，專查三樣：**人物位置**（上一拍還在岸路，下一拍不能已經在棧橋上）、**道具在手狀態**、**誰在場**。寫作時空間狀態在你腦子裡，改的時候它不在——連讀是把狀態找回來的唯一辦法。
- **改畫面，帶聲景。** 劇本動作一改，下游分鏡的描述、聲景、分鏡圖三處要一起動（分鏡 skill 的教訓，源頭在劇本這層就要有意識）。

## 手感規則（不設門，但決定戲好不好看）

- **臺詞短，動作密。** 短劇的對話節奏比電視劇快一倍——兩三句就要有一次動作或反應插進來，超過四句連續對白就悶了。
- **潛臺詞寫進 delivery。**「嘴上讓座，身子沒動」這種表演層的資訊放 `delivery`，別把潛臺詞直接寫成臺詞說破。
- **VO 省著用。** 心聲是強調不是柺杖，一集兩三條封頂；用在「表面平靜、心裡翻江倒海」的錯位時刻最值。
- **人群按大綱的 crowdPlan 拆。** 大綱說了三人以上同框怎麼拆，寫戲時就按那個方案排程——誰在前景說話、誰在背景反應，寫清楚。
- **場次切換是免費的，注意力不是。** AI 換景不要錢，但觀眾每換一次景要重新建立空間感。兩分鐘內換四個景，還不如在一個景裡把戲擰緊。

## 常見病

| 病 | 症狀 | 治法 |
| --- | --- | --- |
| 廣播劇 | 整場只有臺詞 | 每兩三句臺詞之間插一拍畫面動作 |
| 文學病 | 動作寫成美文：伸篙一擋、睫毛顫、退了半寸 | 換成常見動作，判據表見硬規則 4 |
| 開場死畫面 | 第一拍是靜物特寫 | 同一具象換成運動中給（抱箱在霧中跑），靜幀挪到第二次出現 |
| 空間跳變 | 上一拍在岸路跑，下一拍寫棧橋才露出來——或反過來 | 改一拍連讀三拍；人物位置是連續狀態，跳變必須有走過去的拍 |
| 注水 | 寒暄、讓茶、問路佔了半集 | 刪。每一拍要麼推進劇情要麼翻轉關係 |
| 演講癖 | 一個人連說四句 | 拆給對手，或用動作打斷 |
| 全知病 | 臺詞把資訊說盡 | 資訊藏進動作和 delivery，臺詞只說三分 |
| 斷頭戲 | 結尾平收 | 最後一拍換成懸念，哪怕只是一聲汽笛 |
