# script-report.html 設計約定

與 novel-characters / novel-outline / novel-art 的報告同一套視覺語言。改樣式前先讀這份，別憑感覺發揮。

## 基調

- 冷灰印張 + 鐵鏽紅印記：`--paper:#eceded` `--panel:#f5f6f5` `--seal:#8a3324` `--seal-2:#c56a4e` `--ok:#3d6b4f`。這套配色跑過視覺化驗證器，別私自換色
- 頁寬 1600，襯線標題（宋體系）+ 無襯線正文，剋制的分割槽排版，像一份業內評審檔案
- **零外部依賴**：全部樣式內聯、圖形是純 CSS/SVG，離線雙擊能開
- 模型產出的每一個字都要過 `esc()`；內嵌 JSON 的 `<` 轉成 `<` 防 `</script` 截斷

## 區塊順序

KPI 帶 → 01 時長儀表 → 02 分集劇本 → 03 場次總表 → 04 臺詞本 → 05 品質門。時長是錢，儀表放最前；臺詞本是 TTS 的工作清單，放表格之後。

## 時長儀表

- 每集一行：`E01 | 軌道 | 數值`，軌道里三層——目標區間帶（`--band`，半透明綠）、臺詞段（`--seal`）、動作段（`--seal-2`）
- 橫軸比例尺全域統一（取全部集的最大值 × 1.08），行與行可以直接比長短
- 達標的數值用 `--ok` 綠，超欠用 `--seal` 紅加粗並寫明差多少秒——病灶要點名，不許只變個顏色

## 分集劇本

- **一排兩集**：`.eps{display:grid;grid-template-columns:repeat(2,minmax(0,1fr))}`，單集加 `.solo` 單列，窄屏降一列
- 每集卡片裡**場次區預設最多 300px**（`.scenes.clip{max-height:300px}` + 底部漸隱），集頭/鉤子/懸念永遠可見；「展開全部場次 / 收起場次」是**開關**，收起時滾回卡片位置。頁面載入後不超高的集自動放開並移除按鈕（`scrollHeight` 判斷）
- 臺詞行是三列網格 `150px minmax(0,1fr) auto`：說話人（名字 + delivery 豎排）、臺詞、懸停出現的複製按鈕。**滾動/網格容器一律 `minmax(0,1fr)`**，防中文長詞把列擠成一字一行
- 場頭 chips：場景 id+名、光照（seal-2 描邊）、人物、道具（seal 描邊）。給了 `--outline` / `--art` 才顯示名字，否則裸 ID——不猜

## 臺詞本

- **一排兩個**（`.casts` 網格，同 `.eps` 規則），按角色一組一卡，組頭帶句數/字數/約合秒數 + 「複製全部臺詞」（整組臺詞換行拼接，直接餵 TTS）
- 列表**最多 6 行高**（`max-height:186px`）縱向滾動，細捲軸；列印時放開滾動全展開
- VO 單獨成組，顯示為「畫外音」

## 品質門

- 頁首徽章 `✓ 品質門 n / n`；有未過項時 KPI 帶下方掛病灶橫幅（`.galert`），逐條列出未過的門和細節
- 對賬門在缺上游檔案時顯示「跳過（視為透過）」的小字——**跳過要明說，靜默透過和撒謊只差一步**

## 互動與列印

- 複製按鈕統一 `.copy[data-copy]` 事件委託，成功換字 1.6 秒後還原；失敗也要有反饋
- `@media print`：摺疊全展開、按鈕全隱藏、白底
- `prefers-reduced-motion` 關掉全部動效
- 匯出 JSON：資料內嵌在 `<script type="application/json">`，匯出包 Blob 下載，`revokeObjectURL` 延遲 10 秒（Safari 會搶在下載前撤 blob）
