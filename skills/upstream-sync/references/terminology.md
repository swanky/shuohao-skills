# 台灣正體用語對照

這份表是 `upstream-sync` 自己的判斷依據，內容內化自本 repository 根目錄 `CLAUDE.md` 的語言規範（來源：`swanky/shuohao-skills` 的 `CLAUDE.md`「這個 repo 一律用台灣正體中文」一節）。skill 必須自包含、可單獨複製，所以這裡重複一份，不改成連結。

腳本 `../scripts/check-zh-tw.mjs` 只檢查得了「一定錯」的部分——簡體專用字與定案用詞。**一簡對多繁與句法層級的東西腳本判不了，靠這份表和人的判斷。**

## 一、用詞：換字形還不夠

| 別寫 | 要寫 | 腳本抓得到嗎 |
| --- | --- | --- |

| 视频、质量 | 影片、品質 | 抓得到 |
| 信息、数据 | 資訊、資料 | 抓得到 |
| 默认、缺省 | 預設 | 抓得到 |
| 支持 | 支援 | 只提示，語境上偶爾成立 |
| 屏幕 | 螢幕 | 抓得到 |
| 打印 | 列印 | 抓得到 |
| 分辨率 | 解析度 | 抓得到 |
| 性格 | 個性 | 只提示 |
| 水准 | 水準 | 抓得到 |
| 计划 | 計畫 | `計劃` 只提示 |

## 二、一簡對多繁：腳本一律不管

這些字在正體裡對應多個字，選錯就是硬傷，而角色外貌描寫幾乎每次都會踩到。**這類字不進 `SIMPLIFIED_CHARS`**，因為腳本沒有語境。

| 簡 | 看語境選 | 例 |
| --- | --- | --- |
| 发 | 髮／發 | 頭**髮**、一**頭**長**髮**；**發**現 |
| 干 | 乾／幹／干 | **乾**淨、**乾**瘦；**幹**活 |
| 里 | 裡／里 | 眼**裡**、**裡**面；公**里** |
| 松 | 鬆／松 | **鬆**垮、**鬆**弛；**松**樹 |
| 丑 | 醜／丑 | **醜**陋；**丑**角 |
| 面 | 面／麵 | **面**容；**麵**條 |
| 只 | 只／隻 | **只**是；一**隻**手 |
| 复 | 復／複／覆 | 恢**復**；**複**雜；答**覆** |
| 系 | 係／系／繫 | 關**係**；**系**統；維**繫** |
| 表 | 表／錶 | **表**格；手**錶** |
| 板 | 板／闆 | 木**板**；老**闆** |
| 准 | 準／准 | 水**準**、標**準**；**准**許 |
| 通过 | 通過／透過 | **通過**校驗、品質門全**通過**；**透過**管道、**透過**女婿引薦 |

「通过」尤其容易一律換成「透過」——**能不能換成「經由」就是「透過」，能不能換成「合格」就是「通過」**。

## 三、標點與句法

- 引號用「」『』，不要 `""`。
- 中文文案不要為了短而縮成單字詞：「保留／砍掉／合併」不要寫成「保／砍／合」，「安裝」不要寫成「裝」，「使用」不要寫成「用」。章節標題也一樣。
- 排序說法用「依戲份排序」，不用「按戲份排序」。

## 四、絕對不要轉的四處

| 位置 | 維持原樣的理由 |
| --- | --- |
| `novel-characters.mjs` 的 `STRINGS.zh` | 那是 `--lang zh` 這個功能本身；改了簡體報告就廢了 |
| `novel-characters/scripts/selftest.mjs` 裡驗證 `--lang zh` 的斷言 | 改了就驗不到簡體語系輸出 |
| `image.prompt`／`negativePrompt`／`tags`／`sheet`／`voice.prompt` | 永遠英文，生圖與 TTS 引擎吃英文最穩 |
| 範例資料的原文引文（`persona.evidence` 等） | 引文是證據，`validate` 逐字比對，翻了就對不上 |

日文語系表（`ja`）用日文新字體，字形與簡體重疊，同樣不要動。這四處與 `ja` 在 `check-zh-tw.mjs` 的 `ALLOWLIST` 裡都有對應規則，掃描時自動跳過。

## 五、腳本抓不到的，就補進腳本

發現新的漏改型態時：

- 新的大陸用詞 → 加進 `TERM_RULES`，定案用語標 `error`，語境上偶爾成立的標 `warn`。
- 新的簡體專用字 → 加進 `SIMPLIFIED_CHARS`；**一簡對多繁的字不要加**。
- 新的合法例外 → 加進 `ALLOWLIST`，或在原檔用 `zh-tw-lint` 標記豁免。

每次改完 `check-zh-tw.mjs` 都要跑 `node scripts/selftest.mjs`，新規則要一起補反例斷言。
