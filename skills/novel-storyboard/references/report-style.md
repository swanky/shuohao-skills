# storyboard-report.html 設計約定

與另外四份報告同一套視覺語言。改樣式前先讀這份，別憑感覺發揮。

## 基調

- 冷灰印張 + 鐵鏽紅印記：`--paper:#eceded` `--panel:#f5f6f5` `--seal:#8a3324` `--seal-2:#c56a4e` `--ok:#3d6b4f`。配色跑過視覺化驗證器，別私自換色
- 頁寬 1600，襯線標題 + 無襯線正文，零外部依賴，離線雙擊能開
- 模型產出的每一個字都過 `esc()`；內嵌 JSON 的 `<` 轉 `<` 防 `</script` 截斷

## 區塊順序

KPI 帶 → 01 鏡頭節奏帶 → 02 分集分鏡表 → 03 生成批次單 → 04 配音對齊單 → 05 品質門。

## 分鏡節奏帶（招牌圖）

- 每集一行：`E01 | 色帶 | 合計`。色帶按**生成段**分組（`.rseg` 粗分隔 = 段邊界 = 一次生成），組內每個分鏡一片，**片寬 = 分鏡時長 ÷ 全集時長**，顏色 = 鐵鏽紅按景別透明度分檔（大遠景 0.25 → 大特寫 1.0）——深淺相間、長短相間就是好節奏，一眼可讀
- 片是 `<a href="#seg-段號">`，點選跳到段卡；懸停 title 帶段號#切序/秒數/景別/運鏡

## 分集分鏡表

- 每集一個塊，**段卡**兩列網格（`repeat(2,minmax(0,1fr))`，窄屏降檔）；段卡區預設最多 760px 截斷 + 漸隱 + 「展開全部段 / 收起」開關，載入後不超高的集自動放開並移除按鈕
- 段卡：段頭（段號 + 總秒·切數徽章 + 場景/光照 chips + 節拍認領範圍）→ **主分鏡圖** 16:9（`<段號>/f1.png`，缺圖顯示「主分鏡圖 · #1 未生成」+ 提示詞佔位——**不猜、不騙**）→ **子分鏡條**（`.subs` 四列縮略格，f2 起逐格，缺圖小佔位。類名是 `subf`——`sub` 會撞頁首的 `.sub`，踩過）→ **五五分欄**（`.duo`，`repeat(2,minmax(0,1fr))`）：左列分鏡行（#序號、`0.00s 起 · 3s`、景別·運鏡、人物道具 chips、畫面摘要**從劇本認領的節拍自動帶出**、懸停出現分鏡圖提示詞複製），右列**提示詞面板**——預設中文對照（`h3PromptLocal`），頁籤切英文投產版（`h3Prompt`，等寬字型），複製鍵讀當前啟用語言，列表超高自帶細捲軸
- `imageExists` 由 CLI 注入（render 時檢查工作目錄），renderHtml 本體不碰檔案系統——可測性

## 生成批次單

- 同場景 + 同光照一批，兩列卡片；有 `--art` 且場景設定圖在 `images/` 裡就嵌圖（點選放大）
- 批次卡：編號 + 場景/光照 chips + 段號 chips（可點跳轉）+ 一句「需要：誰的角色設定圖 · 哪些道具」

## 配音對齊單

- 一張表：段號#切序（可點）/ 說話人 / 臺詞（襯線）/ 臺詞秒數——TTS 音訊對到哪一段的第幾切，全部自動彙總

## 品質門與互動

- 頁首徽章 + 病灶橫幅 + 文末清單，對賬門缺上游時「跳過（視為通過）」小字明說
- lightbox 點圖放大（首幀圖 + 批次場景圖共用），Esc 關閉
- 複製按鈕 `.copy[data-copy]` 事件委託；匯出 JSON 內嵌 Blob 下載，`revokeObjectURL` 延遲 10 秒
- `@media print`：截斷全展開、按鈕隱藏、鏡頭卡雙列、白底；`prefers-reduced-motion` 關動效
