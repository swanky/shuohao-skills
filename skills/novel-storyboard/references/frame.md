# 分鏡圖生圖 · codex `$imagegen`

生圖走 codex 內建的 `$imagegen` 系統 skill，**不需要任何 API key**——用本機 codex 登入態。**沒有 codex 就整步跳過**，只交提示詞，報告顯示「未生成」佔位，其餘產出照常。

## 分鏡圖是什麼

一個分鏡一張 16:9 關鍵幀，**每段一個資料夾**：`<段號>/f<切序>.png`（f1 = 主分鏡圖），H3 提示詞由 `export` 寫成同資料夾裡的 `prompt.md`（頭部對照表明確 f1.png 是首幀、各圖釘在第幾秒）——整個資料夾拖給 H3 就是一次生成。第 1 切的是**主分鏡圖**（H3 對齊指令把它釘在 0.00 秒），其餘是**子分鏡圖**（各釘在自己的切點時刻）——一段的每一格構圖都由圖控制，不靠文字賭。**它是資產合成，不是憑空畫**：場景、角色、道具長什麼樣已經由上游設定圖定死，分鏡圖只負責把它們按這一格的構圖擺進同一幀。

## 參考圖掛載（命根子）

每一格的 `-i` 清單：

1. **場景設定圖**（`novel-art` 的 `images/<場景名>-sheet.png`）——必掛，環境、材質、光的唯一標準
2. **畫內每個角色的設定圖**（`novel-characters` 的 `images/<角色名>-sheet.png`）——有幾個掛幾個
3. **畫內敘事道具的設定圖**（`novel-art` 的 `images/<道具名>-sheet.png`）——有就掛
4. **鏈式參考**：某角色沒有設定圖時，先出他看得最清的那一格，之後所有帶他的格都拿這張當身份參考（提示詞明寫 the SAME face, same clothes as this reference）——同集的臉不許換人。段的主分鏡圖也值得一直掛著，鎖世界觀和霧的濃度
5. **掛圖按「畫面裡有什麼」，不按「段屬於哪個場」**：段在棧橋場，但畫面裡出現了渡船，就必須把渡船的設定圖也掛上——不掛 = 每幀發明一條新船（踩過）。船、馬車、宅門這類「會入畫的大資產」都同理
6. **提示詞必須寫明人物此刻的位置狀態**：已上船 / 在艙內 / 站在橋頭——切鏡時人物位置是連續的劇情狀態，只寫構圖不寫狀態，模型會把上了船的人又畫回岸上（踩過）

提示詞開頭明說每張參考圖的用途（which is the environment / whose face to match / which prop to match），別讓模型猜。

## 呼叫契約

- **跑在 codex 裡**：直接用 `$imagegen`，不要再 shell 出去調 `codex exec`
- **跑在 Claude Code**：shell 調本機 codex，**先探測版本最高的 binary**（舊版直接報錯），探測腳本抄 `novel-characters/references/sheet.md` 的 `find_codex`
- 所有呼叫套 `env -u NODE_OPTIONS`（codex 繼承壞的 NODE_OPTIONS 會啟動即崩）
- **一鏡一次呼叫，絕不批次**（PNG 位元組會撐爆 rollout）
- 用了 `-i/--image` 這類變長參數時 **prompt 必須走 stdin**
- 提示詞裡明寫「copy to ./<段號>/f<切序>.png」，別讓圖留在 codex 預設目錄
- 提示詞末尾固定加：`No text, no watermark, no borders — a single clean full-bleed frame.`（分鏡圖是乾淨的一幀，不是設定圖，不要格子邊框）
- 單個失敗跳過不阻斷，最後彙總說明
- **不碰 CLI fallback**（要 `OPENAI_API_KEY`）

## 生圖範圍

**預設先出第一段的整套分鏡圖給使用者看效果**（主 + 子共 3–5 張）——畫風、資產一致性、正反打構圖對了再往後補。一集約 30–40 格就是同樣次數的呼叫，方向錯了整批重來。使用者明確說全出再全出。

## 拿到圖先掃一眼

- 和場景設定圖是不是同一個世界（材質、光、舊化程度）
- 角色的臉和衣服對不對得上角色設定圖
- 景別對不對（提示詞寫 close-up 出來卻是全景 → 重生成）
- 有沒有多出來的人（背景圍觀群眾是最常見汙染）——多人就重生成
