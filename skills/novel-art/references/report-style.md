# 美術報告的設計約定

報告由 `scripts/novel-art.mjs render --html` 生成，樣式全部內聯在 `renderHtml()` 裡。**改樣式只改那一處。**

與另外兩份報告同一套視覺語言：冷灰印張 + 鐵鏽紅印記，1600 寬，全部平鋪可 Cmd+F，零外部依賴，離線雙擊能開。

## 結構

```
頁首      劇名 · 場景設定集 · 畫風 · 品質門徽章 · 匯出 JSON
KPI 帶    場景數（主場景 + 變體）/ 一致性錨點 / 光照狀態 / 複用變體
（病灶橫幅）品質門有未過項才出現
01 場景清單    一張總表：ID/型別/出現集/錨點數/光照/變體改動
03 道具清單 04 道具設定卡    有 props 才渲染；道具卡與場景卡同構（狀態變體替代光照，徽章顯示尺度）
02 場景設定卡  每場景一張大卡（報告的主體）
03 品質門     完整 ✓/✗ 清單
```

## 場景設定卡

**一排兩張**（1100px 以下改為單欄），卡內縱排——這個排法是為宣傳截圖設計：設定圖佔滿卡寬、位置靠上，兩張卡並排即可截成一張宣傳圖。

卡內從上到下：卡片標頭（ID + 名稱 + 徽章 + 出現集）→ 設計意圖（宋體，它是敘事而非參數）→ **環境設定圖**（可點選，透過彈出層檢視大圖，按 Esc 或點背景關閉；尚未生圖時顯示佔位）→ 變體來源標註（鐵鏽紅底）→ **一致性錨點**（編號列表，`01 02 03` 等寬序號——它是核對表，編號供 QC 逐項確認）→ **光照與時段**（狀態名 + 提示詞，每行帶複製按鈕）→ 提示詞包（摺疊 + 複製，主視角／設定圖／負向 + 整卡 JSON）。

## 品質門

11 道（場景與共用 7 + 道具 4），`gateReport()` 會在渲染時算好並寫入頁面。沒有道具的檔案會直接放行四道道具門並照常顯示。另有一項特殊處理：「提示詞不含角色名」在未提供 cast.json 時要**明確顯示跳過**（面板寫「未提供 cast.json，本門跳過」），不能假裝已經檢查。

## 匯出 JSON

與另外兩個 skill 採用相同做法：以 `<script type="application/json" id="scenes-data">` 內嵌原始資料，並由頁首按鈕下載。沿用兩項防護：將 `<` 轉成 `\u003c`，避免 `</script` 提前截斷；延後呼叫 `revokeObjectURL`，避免 Safari 儲存出空檔案。

## 品質底線

- 模型生成的資料一律 `esc()` 轉義
- `@media print`：隱藏按鈕、提示詞全展開、卡片不跨頁斷
- `prefers-reduced-motion` 關動效
- 中文文案不用單字詞（複製/展開/主場景，不寫單字）
