# 道具設定 · 怎麼填

給你原文/大綱裡與道具相關的全部資訊，先**選**再**填**。**只輸出 JSON，不要解釋、不要圍欄。**結構見 `schema.md` 的 props 段。

## 先選：哪些項目適合列為敘事道具

三個條件**同時滿足**才入選：**有特寫、跨集出現、承載劇情**。一部劇通常 3–8 件，數量與主角相近。

| 型別 | 歸屬 | 例子 |
| --- | --- | --- |
| **敘事道具** | 入選，單獨建資產 | 皮箱（全劇懸念）、舊硯（爆點實體） |
| 場景陳設 | 場景錨點已覆蓋，不入選 | 銅鈴、紙燈籠、繫纜石樁 |
| 一次性手部道具 | 鏡頭級提示詞解決，不入選 | 一碗茶、一份報紙 |

無法判斷時就問：這件東西是否曾有特寫？觀眾是否記得住？缺少它是否會影響劇情推進？三項皆否就不入選。

## 硬規則

1. **`summary` 寫戲劇功能，不寫商品描述。**「誰碰它，她就跟誰翻臉的懸念核心」是戲劇功能；「棕色牛皮材質」只是材質。先說它在劇裡做什麼。

2. **錨點要經得起特寫。**道具的錨點比場景的更小更細：綠鏽銅釦上的一道新劃痕、墨池邊的月牙磨痕。特寫鏡頭會把這些放大到整個畫面，**缺少會立刻穿幫，太多則難以逐一核對**——維持 3–5 個。

3. **狀態變體從劇情反推。**皮箱有闔上／開啟，狀紙有藏起／攤開——道具的狀態弧隨劇情變化，每個狀態各寫一條英文提示詞並生成一張參考圖。沒有狀態變化的道具只需一個主狀態。

4. **尺度必須明確寫入。**`scale` 三檔（手持級/桌面級/傢俱級），`image.prompt` 和 `image.sheet` 裡**必須出現對應英文短語**（handheld scale / tabletop scale / furniture scale）——AI 把手持道具畫成傢俱尺寸是常見問題，validate 會逐一檢查。

5. **白底、無人、無手。**道具參考圖要合成進各種鏡頭，因此必須使用純白背景、方便去背；**拿著道具的手是最常見的汙染**，負向提示詞必須禁 hands/fingers。`validate` 會檢查這三項。

6. **填寫關聯。**`relatedScenes` 列出它主要出現的場景（id 必須存在），`carriedBy` 寫誰帶著它（自由文字）。這兩項會進入報告，安排生成任務時可用來查詢「這場戲桌上該有什麼」。

7. **提示詞永遠英文，絕不出現角色名**——影像模型會把它認識的名字畫進去。風格整段取用目前預設的渲染句（與場景同一套）。

## 輸入格式

```
Style: realistic
候選道具線索（從原文/大綱摘出）：
- 沈知微始終抱著一隻舊皮箱，指節發白（第 1–6 集，開箱是收束爆點）
- 陸行遠口袋裡的硬東西，第 3 集掏出是一方舊硯，硯底刻著縣衙的印
- 胡二爺的兩箱貨（挑著走，無特寫）
已有場景：S01 渡船船艙、S02 渡口棧橋、S03 對岸蘆葦灘
```

上面第三條不應入選——雖然曾經出場，但沒有特寫，也不承載劇情轉折。
